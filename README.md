# MLAI Government Grant Reporting — Business Demonstration Website

## Run
- Open `index.html` in Chrome, Edge or Safari. No server or dependencies required.
- Or open the separate `MLAI_Grant_Reporting_Demo_v2.html` single-file version.

## Features
- Business-facing Grant Reporting Overview (no Sprint goal, story points or Scrum UI)
- Data Sources register with add/details/filter/search
- Reporting Requirements register with add/details/filter/search
- Source-to-Requirement Mapping with gap/status filters and lineage detail
- Consolidated Schema with table/diagram views
- Synthetic Sample Dataset with client-side data checks and CSV download
- Draft Report Preview with synthetic grant/period selector, generated summary and print view
- Review Notes with demo-only local records
